# IDC 장비 설치 실습 (가상)

새 스위치 1대가 IDC에 입고되어 관제에 잡힐 때까지를 3D로 연습하는 정적 웹페이지입니다.
**장비 모델·시리얼·IP·VLAN·community·센터 구성은 전부 지어낸 가상 값입니다.** 실제 회사·장비와 무관합니다.

## 하는 방법
랙 옆 작업대와 PDU 보관대에 입고된 물건이 놓여 있습니다. **3D에서 물건을 클릭해 집고, 노란 칸(놓을 자리)을 클릭해서 직접 설치**합니다.
Esc 또는 빈 곳 클릭 = 내려놓기. 드래그 = 회전, 휠 = 확대, 우클릭 드래그 = 이동.

## 단계 (빈 랙에서 시작)
1. 입고·검수: 입고서와 현물 대조, 박스가 열립니다. 시나리오는 매번 무작위
2. PDU 설치: 전류 계산(W÷V) → 보관대에서 16A/20A/32A 중 골라 후면 좌우에 설치 → 경보 임계값
3. 랙 마운트: 레일 킷을 U에 달고, 스위치를 방향(포트면 전/후면)을 정해 밀어 넣기
4. 전원 연결: 전원 코드 → PSU 입구 → PDU 콘센트 (A/B 이중화)
5. 광 케이블링: 광 케이블 → 업링크 포트 → 코어 포트 (광 Tx/Rx 극성 문제가 무작위로 발생)
6. 콘솔 설정: 콘솔 케이블을 CON 포트에 꽂고 가상 CLI로 설정 (Cisco 비슷한 문법)
7. 관제 연동: 등록 → ping/SNMP 검증 → 그래프

크기 기준: 1U = 44.5mm, 폭 482mm (1 단위 = 10cm로 그림).

## 실행
```bash
python3 -m http.server 8000   # 열기: http://localhost:8000
node tests/cli.test.js        # 가상 CLI 테스트
# 3D를 실제로 클릭하는 전체 흐름 e2e (Playwright 필요)
node tests/e2e.js http://localhost:8000/
```
