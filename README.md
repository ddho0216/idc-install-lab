# IDC 신입 엔지니어 (가상 현장 실습 게임)

걸어다니며 장비를 직접 집어 랙에 설치하고, **감독관 검수**를 통과하는 3D 게임입니다. (PC 브라우저, 키보드+마우스)
**장비 모델·시리얼·IP·전력·센터 구성은 전부 지어낸 가상 값**이고 실제 회사·장비와 무관합니다.

## 방식
- 순서는 자유입니다. 작업지시서(`Tab`)만 보고 알아서 일하고, 끝나면 감독관에게 말을 걸어 검수를 받습니다.
- 검수는 항목별로 합격/불합격/미완료와 **이유**를 알려 줍니다. 불합격은 점수가 깎입니다. 힌트도 감점입니다.
- 장비 방향·PDU 정격(전류 계산)·A/B 전원 분리·광 극성 등을 직접 판단해야 합니다.

## 레벨
1. **서버 설치**: 박스 개봉 → 입고서 검수 → PDU(전류 계산·정격 고르기·경보값) → 레일 → 서버 장착(방향) → 전원 A/B → UTP 네트워크 → 부팅
2. **스위치 설치**: 레일 → TOR 장착 → 전원 A/B → 광 업링크(코어 2대·극성·라벨) → 콘솔 설정(가상 CLI) → 관제 PC 등록·검증

## 화면 안내
왼쪽 아래 **"하는 방법" 안내판**에 조작키와 단계별 방법이 나옵니다. 지금 할 차례가 강조되고, 손에 든 물건에 따라 사용법이 바뀝니다. `G`로 접고 펼칩니다.

## 조작 (마우스만으로 됩니다)
- **바닥 클릭**: 그곳으로 걸어갑니다 (장애물은 알아서 피함)
- **물건·자리 클릭**: 멀리 있어도 다가가서 집기·사용·설치
- **드래그**: 시점 돌리기 · **휠**: 확대/축소 · **우클릭**: 손에 든 물건 내려놓기
- 오른쪽 아래 **빠른 이동**, 위쪽 **작업지시서·안내판·도움말** 버튼
- 손에 든 장비는 아래 버튼으로 **방향 바꾸기**. 키보드(WASD, E, R, Q, Tab)도 쓸 수 있지만 필요 없습니다.

## 서버실 구조
랙을 마주 보게 두 줄로 놓았습니다. 앞면끼리 마주 본 사이가 **콜드 아일**(지붕·출입문으로 봉쇄, 타공 타일, 온도 18~27℃), 뒷면 쪽이 **핫 아일**(천장 환기구, 비닐 커튼, 약 35℃)입니다. 공기 흐름 화살표가 움직이고, 온도 표시판·냉각 장치(CRAH)를 눌러 설명을 볼 수 있습니다. 장비를 거꾸로 달고 켜면 콜드 아일 온도가 올라갑니다.

## 눌러 볼 수 있는 것들
박스, 클립보드, 태블릿, 노트북, PDU와 LCD, 케이블 끝, 서버 전원 버튼, 감독관, 관제 모니터/PC, 벽시계, 화이트보드, 벽 게시물, 공구함, 소화기, 사다리, 비상 정지(누르면 불합격 +2), 출입문, 타공 타일, 닫힌 랙 문(열고 닫기), 다른 랙의 장비(상태 확인)

## 실행·테스트
```bash
python3 -m http.server 8000     # http://localhost:8000
node tests/cli.test.js          # 가상 CLI 단위 테스트
node tests/play1.js http://localhost:8000/   # 1레벨 자동 플레이 (Playwright)
node tests/play2.js http://localhost:8000/   # 2레벨 자동 플레이
node tests/mouse.js http://localhost:8000/   # 실제 마우스 이벤트로 클릭 이동·상호작용 확인
```
빌드 과정이 없습니다. Vercel에서는 이 폴더를 그대로 Import하면 됩니다. three.js(`vendor/`)는 MIT 라이선스입니다.
